# Mzansi Artisan Core

Reusable, trade-independent core for the Mzansi Artisan Factory.

## Build status

**MAF-02-04 — Universal Core Skeleton**

This repository is being extracted from proven components in the existing Mzansi Boilermaker PWA. The production Boilermaker repository remains untouched and acts as the benchmark.

### Existing-Asset-First rule

**DISCOVER EXISTING → INGEST → AUDIT → VERIFY → REUSE → RESEARCH GAPS → BUILD**

### Core boundary

The Core contains behaviour. Trade Packs contain trade knowledge.

Initial skeleton scope:
- local storage engine
- Trade Pack loader
- offline/service-worker foundation

Build doctrine: **ONE SMALL BUILD → TEST → VERIFY → FREEZE → NEXT BUILD**

### Visual-learning reference standard

All artisan trade builds must include the reusable visual-learning reference module defined in `core/VISUAL_LEARNING_REFERENCE_STANDARD.md`. Offline lessons remain complete on-device; vetted online visual resources are optional reinforcement only when connectivity is available.
